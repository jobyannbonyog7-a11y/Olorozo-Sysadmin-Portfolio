# System Administrator Career Portfolio - Green Monochrome (Binary Rain) Edition

Stack: HTML5, CSS3, vanilla JavaScript. No build step, no database.

## Before submitting
1. The profile photo is `images 09.jpg` in the project root. Update its `src` in `index.html` if you use a different filename.
2. Update the personal details in `index.html` and `terminal.js` when reusing this portfolio.
3. Change the course in index.html (About section) if needed.
4. Open `index.html` (or use VS Code Live Server).

## Files
- index.html          Home, Roles, Skills, Tools, Linux Terminal, About
- css/style.css       Green monochrome dark theme, chamfered frame, responsive
- js/rain.js          Falling 0 and 1 background (lights up near the mouse)
- js/translations.js  English / Filipino
- js/terminal.js      Simulated Linux command prompt
- js/main.js          Translator, navigation, cards, effects
